# Screenshots

The images beside this file are the ones the README shows. They are taken from a throwaway
installation rather than anyone's real setup: the connections are invented, the hosts
(`nas.harbour.example`, `build-01.example.internal`) resolve nowhere, and the files are a generated
tree under `C:\StorageHub-Demo` whose contents are empty sparse files with plausible names, sizes,
and dates.

To remake them, point StorageHub at an empty data directory (`STORAGEHUB_DATA_ROOT`), import a
settings export holding the demo connections, and capture the window rather than the screen, so
nothing behind the application ends up in a picture that ships. They are deliberately taken at 125%
scale in the dark theme, which is what the application looks like on the machine it is developed on.

Name each one after what it shows. A file named for the tool that captured it tells a reader
nothing, and the README's alt text has to be written from the picture either way.
